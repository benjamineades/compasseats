★ The one rule that governs everything

A venue shows on the site only when it's in the venues tab, has at least one accolade, and has its required fields filled — name, type, city, address, lat/lng. Miss one → it waits in needs_enrichment. That's what "charted" means: sheet-matched-with-an-accolade.

Two ways to do it
Path A · a whole award list
Paste into the import tab (bars → makeBarImportTemplate + ingestBarLists; restaurants → makeRestaurantImportTemplate + ingestRestaurantLists) → ingest fills the Bar Awards / Restaurant Awards tab → run reshape.gs to fold into venues → enrich gaps → re-run cities.gs if new cities → publish in Lovable. New award source? Add it to AWARD_SOURCES in schema.ts first.
Path B · one venue by hand
Add a row in venues → fill name, type, city, country, address → add lat/lng → add ≥1 accolade → confirm city matches a cities row → publish in Lovable.
B

Run the Scripts

in order
Order matters
1
reshape.gs
Merges all award tabs + enrichment → venues; sends incomplete rows to needs_enrichment; de-dupes. Run after any list change.
2
cities.gs
Builds cities with centroid lat/lng. Preserves your manual edits (hero image, timezone) on re-run.
3
bar-ingest.gs
Bar importer: makeBarImportTemplate + ingestBarLists. Writes to the Bar Awards tab (reshape reads it). Use when adding a bar list.
4
restaurant-ingest.gs
Restaurant importer: makeRestaurantImportTemplate + ingestRestaurantLists. Writes to the Restaurant Awards tab (reshape reads it). Grades go in category_override.
5
photos.gs  ⚠️
Hold. Bills per image load — cache to a CDN first, then point photo_url at the cached copies.
How to run any one
  1. Extensions → Apps Script in the Sheet
  2. Click the script file, pick the function
  3. Hit ▶ Run (authorize on first run)
  4. Watch the Execution log → back to the Sheet
Canonical full-pipeline order (after any list/data change)
  1. reshapeCompassEats — fold all award + enrichment tabs into venues
  2. mergeDuplicateVenues — collapse same-venue duplicate rows
  3. importBlurbsFromDrive — reload bulk blurbs (reshape blanks them)
  4. clearWrongCityBlurbs — strip blurbs that landed on the wrong city
  5. importOptionB — reload the sourced rich (Option B) blurbs
  6. generateCitiesTab — rebuild cities (preserves manual edits)
  7. Regenerate the four data/*.json from a Sheet export
  8. GitHub web → Add file → Upload files (drag-drop replace) → Publish
Then: regenerate the four data/*.json files from a Sheet export → upload via GitHub web → Add file → Upload files → Publish in Lovable (build prints SYNC SKIPPED — expected; Build Secrets require Business/Enterprise plan) → verify on compasseats.com in a fresh tab. Lovable modes: use Chat for diagnostics (read-only), Plan for large changes, Build to apply fixes. Never click "Try to fix" on a build error without reading the Details first. Hero photo? Paste a bare images.unsplash.com URL into hero_image_url, publish.
