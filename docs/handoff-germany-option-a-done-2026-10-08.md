## Methods that worked (new)
- **Option-A update from a promoted batch:** build the plan from `ingest_rows` of the batch (verdict `duplicate`, `validation->'collides_with'->>0` = award id), joined by line to fixture values generated by script. Gate on the batch fingerprint, the fixture md5, the plan fingerprint and the award id md5. One `UPDATE`, one ledger row, audit rows checked by `row_pk` and "only `source_url` changes".
- **Short dry run for a large file:** in the Read connector, send the `DO` block with the `VALUES` list replaced by a `SELECT` of the same columns from `ingest_rows`. The fixture md5 gate still checks the values. The real run sends the exact file.
- **Write connector with a large file:** the full 65 KB file (483 `VALUES` lines) ran in one call with no "cancelled" result. Read the file in two parts (Read tool limit 25,000 tokens), then send it exactly. The md5 gate protects against a copy error.
- **URL shape for Michelin Germany cards:** some city segments hold `_1234567` or `(jagst)`, and some slugs hold `%C2%B0` or `%C2%B4`. Use `[^/]+` per segment, not `[a-z0-9-]+`.
